# Default mascot

`sleeping-cat.png` is AI-generated art created with OpenAI image generation for this widget. Its transparent PNG scales into the small image slot. Source-generation metadata is excluded from the public copy; image pixels are retained.

Choose your own image in Settings. Recommended size: 300 × 200 pixels, preferably transparent PNG. Custom image copies are kept in your private local `data/images` directory, which is not distributed or tracked.
